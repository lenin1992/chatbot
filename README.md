# 🤖 AI Chatbot with Google Search & FAISS

This is an intelligent AI chatbot built with **LangChain**, **OpenAI GPT**, and **Streamlit**, capable of:
- 🔍 Retrieving answers from a **local FAISS vector store** using OpenAI embeddings
- 🌐 Enriching context with **live web results from Google Custom Search**
- 💬 Handling small talk and greetings naturally
- 📈 Providing **live stock price updates** (e.g., SBI via yFinance)
- 🧠 Storing and updating knowledge base using FAISS and Google results

---

## 🚀 Features

- **FAISS Vector Search**: Retrieves semantically relevant documents from a local index.
- **Google Search Integration**: Fetches latest web data using the Google Custom Search API.
- **Stock Price Tracker**: Periodically updates FAISS with live SBI stock prices using yFinance.
- **Environment Variable Management**: .env handling for secure API access.
- **Streamlit Frontend**: Intuitive UI to interact with the chatbot.
